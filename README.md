🎯 Resumo do App
FinançasIA é um aplicativo de organização financeira pessoal que funciona por meio de conversas naturais com um agente de IA — o Finn, um consultor financeiro virtual.
Em vez de preencher planilhas ou categorizar gastos manualmente, o usuário simplesmente conversa: "Gastei R$ 32 no almoço hoje" — e o Finn entende, registra, categoriza e sugere ações.

🧠 Prompt Final — PRD

Quero criar um app de finanças pessoais chamado FinançasIA com um agente de IA chamado Finn.

Problema: pessoas desistem de controlar gastos porque os apps exigem muita entrada manual.

Solução: registrar gastos por conversa natural, com categorização automática e dicas personalizadas.

Público: 18–35 anos, iniciantes em finanças.

Funcionalidades do MVP:
1. Chat para registrar gastos em linguagem natural
2. Categorização automática das transações
3. Metas financeiras com acompanhamento
4. Agente Finn com dicas de economia personalizadas
5. Relatório mensal simples com gráfico

Me gere o conceito visual das telas principais deste app.
🖥️ Interações com a IA
Interação 1 — Prompt enviado ao Lovable
O PRD foi inserido no campo de texto do Lovable. A interface reconheceu o contexto e iniciou o projeto com o nome "Bate-papo e rastreamento", confirmando que o prompt estava claro e bem estruturado.
Interação 2 — Lovable gera o conceito visual
O Lovable respondeu: "Conceito visual do FinançasIA pronto — 4 telas (Conversa, Início, Metas, Relatório) em mockups mobile com a paleta verde sálvia + laranja e o Finn como agente."
Interação 3 — App funcional gerado
O Lovable criou o app completo com: Login, Painel, Chat com Finn (IA real), Metas e Relatório. Tudo persistido em banco de dados com autenticação por usuário.

💭 Reflexão sobre o Processo
✅ O que funcionou bem
A clareza do PRD fez toda a diferença. O Lovable surpreendeu ao transformar um simples briefing em app funcional real com banco de dados, autenticação e chat com IA integrada.
❌ O que não funcionou como esperado
O limite de 5 interações diárias do Lovable exige planejamento. Tive também um erro de workspace no início que precisou ser resolvido antes de criar o projeto.
📚 O que aprendi sobre conversar com IAs
IA é parceira, não mágica. Ela amplifica sua intenção — se a intenção é vaga, o resultado é vago. Vibe Coding não é sobre código: é sobre transformar ideias em linguagem que a IA entende.
